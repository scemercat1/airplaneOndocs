# ✈️ AirplaneON

Welcome to **AirplaneON** – a powerful Discord moderation bot that can be used **either as a self-hosted bot** or through the **official free original version**.

This documentation explains:
- What AirplaneON is
- The difference between Self-Hosted and Original version
- Licensing rules
- How to use and host the bot safely and correctly

---

## 🔍 What is AirplaneON?

AirplaneON is a modern Discord moderation bot focused on:
- Security
- Transparency
- Full control
- No unnecessary dashboards

All important actions are handled directly inside Discord.

### 🛠️ Self-Hosted Version

You can also **self-host AirplaneON** on your own infrastructure (Railway, VPS, etc).

With self-hosting:
- You control everything
- You host the bot yourself
- You are responsible for setup and maintenance

⚠️ **Important License Rules for Self-Hosting**  
- The self-hosted version **may ONLY be used on your own Discord servers**
- You are **NOT allowed to resell, redistribute, or provide the bot to others**
- Offering the self-hosted bot to third parties **violates the license**

Self-hosting is intended for **personal or internal use only**.

---

## ⚙️ Key Features

- Slash-command based moderation
- Role-based permission system
- Owner-only configuration commands
- Designed for self-hosting platforms like Railway
- No external dashboards
- No data selling or tracking

---

## 🔒 Privacy & Transparency

AirplaneON does **not**:
- Log message content
- Track user activity
- Send data to third-party services

If you self-host it, **all data stays with you**.

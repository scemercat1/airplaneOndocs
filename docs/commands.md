## 🛡️ Moderation

- `/warn` – Warn a member with a reason  
- `/mute` – Timeout a member for a number of minutes  
- `/unmute` – Remove timeout from a member  
- `/ban` – Ban a member from the server  
- `/unban` – Unban a user using their user ID  
- `/kick` – Kick a member from the server  
- `/clear` – Delete a number of messages from a channel  
- `/lock` – Lock a channel (disable messages for @everyone)  
- `/unlock` – Unlock a channel  
- `/slowmode` – Set slowmode delay for a channel  

---

## 👤 Member Management

- `/nick` – Change a member’s nickname  
- `/role_add` – Add a role to a member  
- `/role_remove` – Remove a role from a member  

---

## 📢 Utility / Server Tools

- `/announce` – Send an announcement message  
- `/poll` – Create a simple yes/no poll  

---

## ⚙️ Admin (Owner Only)

- `/config` – Configure which roles are allowed to use moderation commands  

---

## 🔐 Permission System

Only users with roles configured using `/config` can use moderation commands.  
The `/config` command itself can **only be used by the bot owner**.
